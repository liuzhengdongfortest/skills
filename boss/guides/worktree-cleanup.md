# 工作区清理指南

工作区清理服务于“可追踪、可交接、可继续推进”的原则，不是为了追求形式上的 clean。

每轮 task 收尾必须运行：

```bash
git status --short --untracked-files=all
```

然后处理剩余改动：

- 本 task 漏提交的文件：补进本 task commit，或追加一个只包含漏文件的 follow-up commit。
- 其他已知任务的改动：边界清楚且验证明确时，单独提交到对应任务；任务仍在进行中时，写入对应 task 执行记录。
- 用户手动改动或来源不明改动：不要提交，记录文件列表和不提交原因。
- 无关但可安全归因的清理、文档或配置变更：优先单独提交成小 commit，不让它滚到下一轮。

收尾目标是：工作区尽量干净；不能干净时，剩余文件必须有归属、有原因、有下一步。
